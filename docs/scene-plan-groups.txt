# The groups of docs/scene-plan.md: python tools/coverage.py --plan docs/scene-plan-groups.txt
# Each function no scene enters goes to the first group with a matching pattern (file or
# file:Name, file relative to clean/ without .c), so the specific groups come before the broad
# ones. needs: seed (a scene from the seed save on its day), date (another date, time, weather or
# a visitor: for the boot on another day), unknown (the trigger is not identified yet),
# unreachable (a second system, a server or a hardware event the recordings cannot make).
