# not in this repository). As friend-code.txt to 3800: the friend code keypad of the pockets'
# friend roster (ov133/friend_code_entry.c).
# Save: the seed town. A tap at 3800 (taken as the first touch); the pen enters 541178224974,
# a friend code NitroDWC takes for this game: the low 32 bits a profile number (12345678) and
# the high ones the low 7 bits of the CRC-8 (polynomial 7) of that number and the game code of
# the player's account data ("KMDA" at 0x24 of the account, 0x1f0c of the player's record), as
# DWC_Acc_CheckFriendKey tests it. Decide (4196, 4242): not the player's own code nor another
# friend's; the friend's name and town are typed on the keyboard (4308-4574) and the roster
# shows the friend. The pen opens the friend's choice (4700) and its "change the code" row: the
# keypad with the friend's code, decided again (4888, 4934). By the keys from 5040: LEFT onto the
# friend, A opens the choice, DOWN and UP, B cancels; A, DOWN to delete and A: the question,
# answered no; again, UP to yes and A (5822): the friend is deleted. The pen opens Register's
# choice and cancels it (5942, 5998), and the arrow (6084) closes the page.
